# 0.3 Optional Python Crash Course for Remote Sensing

Notebook: `intro_to_python.ipynb`

## What you will do

Learn the foundational Python syntax and concepts—including variables, NumPy array indexing, and basic Matplotlib plotting—required to run the Sentinel-2 tutorial notebooks.

## Requirements

- No specific accounts required.
- [0.1 Setup](../0.1_Setup_and_Environment/) completed.

## Data

This notebook uses synthetically generated dummy data (`numpy.random`) to demonstrate core concepts. No external satellite datasets are required, and no files are written to your local drive.
